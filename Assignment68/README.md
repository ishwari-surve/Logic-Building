# Assignment 68

## Description

This assignment focuses on solving real-world problems using Java Collections and data structures.

## Questions Covered

### 1. Employee Attendance Analyzer
- Stores employee IDs.
- Counts the frequency of each employee ID.
- Displays each employee ID along with its frequency.

### 2. First Non-Repeating Character
- Takes the word `programming`.
- Finds the first character that occurs only once.
- Expected result: `p`.

### 3. E-Commerce Product Inventory
- Maintains product inventory using product IDs and quantities.
- Supports operations such as:
  - ADD
  - SELL
  - RESTOCK
  - SEARCH
- Displays the available quantity of a requested product.

### 4. Duplicate Transaction IDs
- Stores transaction IDs.
- Identifies transaction IDs that occur more than once.
- Displays the duplicate transaction IDs.

### 5. Student Marks Sorting
- Stores student names and marks.
- Sorts students based on:
  - Marks in descending order.
  - Alphabetical order when marks are equal.

## Concepts Used

- Java
- HashMap
- LinkedHashMap
- ArrayList
- Collections
- Comparator
- Frequency Counting
- Sorting
- Searching

## Expected Learning

- Understand Java Collection Framework.
- Work with key-value pairs using Maps.
- Count frequencies efficiently.
- Perform sorting using Comparators.
- Solve practical data-processing problems using Java Collections.
