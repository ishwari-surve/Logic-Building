# Assignment 57 - Logic Building

This assignment focuses on string-based logic building and problem solving using Python.

The programs are designed to perform different string operations such as reversing words, finding the longest word, removing duplicate characters, counting vowels and consonants, and checking whether one string is a rotation of another.

## Objective

The main objective of this assignment is to:

* Improve logical and analytical thinking
* Understand string manipulation techniques
* Process sentences and strings character by character
* Reverse individual words in a sentence
* Find the longest word in a sentence
* Remove duplicate characters from a string
* Count vowels and consonants separately
* Check whether one string is a rotation of another
* Develop structured string-processing solutions

## Approach

Each problem is analyzed to understand the required string operation.

The solution is implemented by processing strings and applying suitable logic such as:

* Splitting a sentence into individual words
* Reversing characters while maintaining word order
* Comparing the length of words to identify the longest word
* Traversing a string to remove duplicate characters
* Checking each character to count vowels and consonants
* Comparing two strings to determine whether one is a rotation of the other

The programs use suitable loops, conditions, and functions to implement the required logic.
