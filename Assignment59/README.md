# Assignment 59 - Logic Building

This assignment focuses on number-based logic building and mathematical problem solving using Java.

The programs are designed to analyze different properties of a given number by performing mathematical calculations, processing digits, and applying specific conditions.

## Objective

The main objective of this assignment is to:

- Improve logical and analytical thinking
- Understand different number properties
- Practice digit-by-digit number processing
- Perform square and cube calculations
- Calculate the sum and product of digits
- Check whether a number is a perfect square
- Perform power calculations
- Compare calculated results with the original number
- Develop structured problem-solving approaches

## Approach

Each problem is analyzed to understand the mathematical property of the given number.

The solution is then implemented by breaking the problem into smaller logical steps such as:

- Extracting individual digits
- Calculating the square or cube of a number
- Calculating the sum or product of digits
- Checking whether a number is a perfect square
- Calculating powers of digits
- Comparing the calculated result with the original number
- Checking whether the square or cube ends with the original number

The programs use suitable loops, conditions, mathematical operations, and functions to implement the required logic.
