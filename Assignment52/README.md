# Assignment 52 - Competitive Coding

This assignment contains competitive coding and logic-building problems based on real-world scenarios.

## Questions

### Q1 - Book Fine Calculator

Calculate the fine amount based on the number of days a book is kept beyond the allowed period.

### Q2 - ATM Withdrawal

Validate and process an ATM withdrawal while maintaining transaction and minimum-balance rules.

### Q3 - Student Result

Calculate student results based on subject marks, average marks, and classification criteria.

### Q4 - Electricity Bill

Calculate the electricity bill using progressive unit-based billing slabs.

### Q5 - E-Commerce Discount

Calculate the final payable amount based on purchase amount and membership type.

## Concepts Practiced

- Conditional Statements
- Nested Conditions
- Input Validation
- Arithmetic Operations
- Percentage Calculation
- Logical Operators
- Real-World Problem Solving
- Competitive Coding Logic
