# Assignment 58 - Logic Building

This assignment focuses on number-based logic building and mathematical problem solving using Java.

The programs are designed to analyze different properties of a given number by processing its digits, calculating mathematical values, finding divisors, and applying specific conditions.

## Objective

The main objective of this assignment is to:

- Improve logical and analytical thinking
- Understand different number properties
- Practice digit-by-digit number processing
- Apply mathematical operations in programming
- Use loops for repeated calculations
- Implement factorial and power calculations
- Find proper divisors of a number
- Calculate the sum of digits
- Reverse a number
- Develop structured problem-solving approaches

## Problems Covered

The assignment includes programs based on:

- Strong Number
- Armstrong Number
- Perfect Number
- Harshad Number
- Palindrome Number

## Approach

Each problem is analyzed to understand the mathematical property of the given number.

The solution is then implemented by breaking the problem into smaller logical steps such as:

- Extracting individual digits
- Performing calculations on digits
- Finding factorials
- Calculating powers
- Finding proper divisors
- Calculating the sum of digits
- Reversing the given number
- Comparing the calculated result with the original number

The programs use suitable loops, conditions, and functions to implement the required logic.
